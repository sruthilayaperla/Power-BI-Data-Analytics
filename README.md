# Power BI Data Analytics

A collection of Power BI case studies covering sales analysis, employee-data cleaning, e-commerce/customer analysis, and exploratory analysis of suicide data in India.

## Case Studies
1. `01-sandwitchsales/` — Sandwich sales analysis with CSV, PBIX, report, and screenshots.
2. `02-sandwitchsales/` — Sandwich sales analysis with CSV, PBIX, QA document, and screenshots.
3. `03-Suicides in india/` — 2001–2012 analysis with CSV, PBIX, QA/report documents, and screenshots.
4. `E-Commerce Sales & Customer Analytics/` — E-commerce/customer analysis dataset, questions document, and screenshots.
5. `dirty employees/` — Employee-data cleaning and analysis with CSV, PBIX, and report.

## Tools
Microsoft Power BI, Power Query, DAX, CSV data, data cleaning, transformation, modeling, visualization, and dashboarding.

## Workflow
Source data → quality review → cleaning/transformation → Power BI model → DAX/measures → visualizations → analysis.

## How to Explore
Open a case-study folder and read its local README first. PBIX files require Power BI Desktop. CSV files provide source data, while screenshots and documents provide supporting material where available.

## Notes
This repository contains Power BI binary reports and Word documents in addition to text-readable source data. This README does not claim numerical findings that are not documented in the repository.
