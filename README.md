## Tools and Techniques

- **Power BI Desktop** — report authoring and interactive dashboards
- **Power Query** — data import, cleaning, and transformation
- **DAX** — measures and analytical calculations
- **Data modeling** — organizing fields and relationships for reporting
- **Data visualization** — KPI cards, charts, tables, and filters

## Typical Analytics Workflow

1. Identify the business question and inspect the source data.
2. Check field types, missing values, duplicates, and data quality.
3. Transform the data with Power Query.
4. Build and validate the model.
5. Create DAX measures and KPI calculations.
6. Develop report pages and interactive filters.
7. Review the results and document evidence-based findings.

## How to Review a Case Study

1. Open a linked project folder above.
2. Read its project README/report, where available.
3. Review the screenshots to understand the report layout.
4. Open the `.pbix` file in Power BI Desktop to interact with the report.
5. Use the included CSV/source files to understand the input data where provided.

Power BI Desktop is required to open and edit PBIX files. Screenshots are static previews and do not replace the interactive report.

## Portfolio Notes

This repository contains PBIX files, CSV datasets, screenshots, and supporting Word documents. Numerical findings should be taken from the relevant workbook/report, not inferred from the project title or folder name. The public-data case study concerning suicide statistics should be interpreted carefully and in its original statistical context.
